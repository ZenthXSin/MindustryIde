## 方法

以 package 为主分组，以文件为单位逐个分析。每个 package 页列出该包内每个文件的：

- 文件级知识页链接
- 源码绝对路径
- SHA1
- 类型声明
- 字段线索
- 方法线索

完整源码仍以本地仓库为准；知识页负责定位、索引与结构化理解。
