For Mindustry mod questions, search in this order:

1. Knowledge base pages
2. Local `mods/` examples and reference projects
3. Source code / implementation details

## Universal Hit Rule

When a query is broadly related to Mindustry modding, treat this page as a general hit and route the search toward `mods/` first.

## Why this matters

The `mods/` directory often contains practical examples, JSON structures, and implementation patterns that answer the question faster than reading source code directly.
